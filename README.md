# Hunar Rozgar — District Employment Intelligence Network (Static Demo)

**Every Skill Deserves an Opportunity.**
Connecting Pakistan's workforce with real employment opportunities through AI.

This repository hosts the **static demo** of Hunar Rozgar, a District Employment Intelligence Network starting in Sindh, Pakistan. It is a single self-contained page (`index.html`) for GitHub Pages.

## What the demo shows

- Hero, live employment statistics, How It Works, and 7 job categories (Construction, Agriculture, Healthcare, Transport, Technical Skills, Domestic Services, IT & Freelancing)
- Interactive Sindh district tile grid (a tile grid, not real map boundaries) — tap a district for its stats
- AI voice registration demo in Urdu / Sindhi / English — the sample "Main Raj Mistri hoon aur Thul mein rehta hoon." extracts Mason / Construction / Thul / 8 years / Rs 1,500 / Immediately into an editable profile preview
- Worker, Employer, Government and Admin demo dashboards, with charts, a district heatmap and CSV report download
- 4-tier pricing: Worker Free, Employer Monthly, Enterprise Custom, Government Annual district license
- English / Urdu / Sindhi language toggle (Urdu in Nastaliq script)

## Important — demo only

- **Static demo: registration and data saving do NOT work.** All data shown is sample data, clearly marked DEMO.
- No real government partnership is claimed. Testimonials are samples.
- The full working app (with database and server-side AI) stays private in Muse; this repo contains the demo version only.
